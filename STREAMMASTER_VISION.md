## 🔥 Technical Architecture

### Multi-Layer Scraping
```javascript
Layer 1: Debrid Cache Check
  ├─ RealDebrid cached?
  ├─ AllDebrid cached?
  ├─ Premiumize cached?
  ├─ Torbox cached?
  └─ If cached: INSTANT STREAM ⚡

Layer 2: Jackett/Prowlarr
  ├─ Query configured indexers
  ├─ Private trackers
  ├─ Public trackers
  └─ Return top results

Layer 3: Direct Scrapers
  ├─ 1337x, TPB, Galaxy, etc.
  ├─ Parallel requests
  ├─ Deduplication
  └─ Quality scoring

Layer 4: P2P Fallback
  ├─ WebTorrent
  ├─ Direct magnet
  └─ DHT peers

Layer 5: Usenet (Optional)
  ├─ NZB indexers
  ├─ SABnzbd integration
  └─ Premium access
```

### Aggregation Engine
```javascript
1. Collect from ALL sources simultaneously
2. Deduplicate by info hash
3. Merge metadata (quality, size, seeders)
4. Apply quality scoring algorithm
5. Check availability across debrid services
6. Rank by: cached > quality > seeders
7. Return prioritized stream list
```
