Pipeline

Four stages, one request

Every stream request runs the same deterministic pipeline under a hard time budget. Nothing waits on a slow tracker — whatever has arrived by the deadline gets ranked and returned.

01 / RESOLVE

Identify the title

The IMDb id from your client is resolved through Cinemeta into a title, year and episode — cached for 12 hours.

02 / FAN OUT

Scrape in parallel

Enabled sources fire simultaneously with per-source timeouts. A dead tracker costs you nothing but its own slot.

03 / PROBE

One cache call

Every unique infohash goes to TorBox in a single checkcached request. Cached results jump to the top.

04 / RANK

Score and format

Resolution, source, codec, seeders and cache state combine into a single score. Deduplicated across trackers.

Engineering

Built for the free tier

Most addons fall over on serverless because they assume a long-running process. Hydra is designed around the opposite constraint.

⚡

Batch cache probing

A hundred hashes checked in one HTTP call instead of a hundred. This is the single biggest speed win available from a debrid API.

🔗

Lazy resolution

Stream URLs point at Hydra, not TorBox. The direct link is minted the instant you press play — no torrents added to your account for results you never open.

🌊

Native P2P

Uncached results are returned as an infohash plus trackers. Your client does the peer work, so Hydra never proxies a byte of video.

📦

Zero dependencies

No SDK, no axios, no cheerio. Pure Node built-ins, which means a ~50ms cold start and nothing to break on a supply-chain update.

🔒

Opaque config URLs

Set one environment variable and your entire configuration — API key included — is AES-256-GCM encrypted inside the addon URL.

🎯

Release intelligence

Names are parsed into resolution, source, codec, HDR, audio and release group. CAM rips with 900 seeders never outrank a 4K REMUX.

Your choice

Debrid, P2P, or both

You should not have to pick a side. Hydra runs whichever path makes sense for each result, and you decide how far it is allowed to go.

Hybrid default

Cached results stream from TorBox instantly. Everything else is handed to your client as P2P.

  • Maximum number of playable results
  • Cached first, peers as backup
  • Best choice for most people

Debrid only fastest

Only show what TorBox can serve right now. No buffering, no peers, no waiting on a swarm.

  • Instant start on every result
  • Zero bandwidth from your connection
  • Needs an active TorBox plan

P2P only no account

TorBox is never contacted. Every result is an infohash and your client streams straight from the swarm.

  • Works with no subscription at all
  • Nothing is stored on any server
  • Your IP is visible to peers
