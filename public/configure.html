Step 2 — Sources

Where to search

Public trackers are blocked unevenly depending on your network. Test them and keep only the ones that answer — the dead ones cost you nothing but time.

Runs a live search for one film
Torznab endpoint — Jackett, Prowlarr, or any indexer What is this?
One endpoint here can unlock hundreds of private trackers. Paste the “Torznab Feed” URL from Jackett, or a Prowlarr indexer URL.
Proxy — optional, fixes Cloudflare-blocked sources
Some trackers fingerprint the TLS handshake and refuse server traffic — a User-Agent will not help, only a different exit point will. Paste a proxy prefix, or a template containing {url}. Leave empty to fetch directly.
Free option: deploy the bundled Cloudflare Worker (worker/index.mjs) — no server, no card. Open <worker-url>/__check to confirm it can reach the trackers before relying on it.

Exact matching drops releases that are a different film — a remake, a sequel, or an unrelated result from a text search. Hide unreleased goes further: if the film has not opened, or the episode has not aired, every result claiming to be it is fake, so none are shown. Turn either off if something comes back empty and you would rather see everything and pick yourself.
